# Support

## Using the app

The [About page](https://lightsout.org.za/about) explains what Lights Out is, how a report is handled and what is collected.

## Something is not working

[Open a bug report](https://github.com/Chester-xx/lights-out/issues/new/choose). Check the status badges at the top of the [README](README.md) first. If one is red, the problem is probably already known.

## A faulty light or signal

Report it in the app at [lightsout.org.za](https://lightsout.org.za). Issues in this repository are not read as fault reports.

## Emergencies

Lights Out is not an emergency service. If a fault is causing immediate danger, call the police on 10111, or 112 from a mobile phone.

## Security problems

Use [private reporting](https://github.com/Chester-xx/lights-out/security/advisories/new). See [SECURITY](SECURITY.md).

## Response time

Lights Out is a student project run in spare time. Responses depend on the maintainer's available time, so no response time is promised.
