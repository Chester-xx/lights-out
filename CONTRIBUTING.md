# Contributing

Thank you for helping to improve Lights Out. This repository takes problem reports and suggestions. It does not take code, because the source code is not published here. Please do not open pull requests.

## Before you open an issue

- Look through the [open issues](https://github.com/Chester-xx/lights-out/issues) in case yours is already there. Add to that one instead of opening a new one.
- To report a faulty light or signal, use the app at [lightsout.org.za](https://lightsout.org.za). Issues here are for problems with the app itself.
- For a security problem, use [private reporting](https://github.com/Chester-xx/lights-out/security/advisories/new) and not an issue.

## Opening an issue

[Open an issue](https://github.com/Chester-xx/lights-out/issues/new/choose) and pick one form:

- **Bug report:** something does not work or looks wrong.
- **Improvement:** an idea that would make Lights Out better.

One problem or idea per issue. Say what you saw, what you expected, and which page, phone or browser you used.

## Keep personal information out

Issues are public. Do not include names, phone numbers, email addresses, home addresses or photos of people. A screenshot is fine if it shows no personal information.

## What to expect

Lights Out is a student project run in spare time. Responses depend on the maintainer's available time, and not every suggestion will be added. Please follow the [code of conduct](CODE_OF_CONDUCT.md).
